A short catalogue of public sources this reference actually uses. Prefer these over a blog post that restates them. When a vulnerability note and a catalogue disagree, the primary source wins, and the note should be corrected.

| Page | What it collects |
| --- | --- |
| [Standards](standards.md) | OWASP, MITRE, NIST, FIRST, and related public frameworks. |
| [Tools](tools.md) | Maintained tools for discovery, manual testing, and defensive review. |
| [Learning](learning.md) | Training and practice platforms that publish their own material. |
| [Vulnerability classes](vulnerability-classes.md) | Where to read each class in depth, and which local note matches which public test. |
| [Payload and wordlist libraries](payload-libraries.md) | Upstream payload catalogues and wordlists. Named and linked. Not copied into this repository. |

Every link was chosen because it is a primary or long-standing public reference. If a link rots, replace it with the successor on the same project. Do not replace it with an unverified mirror.
