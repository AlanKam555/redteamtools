# Learning

Practice on systems built for practice, or on systems you operate. A public lab is not a permission slip for a company's production name that happens to use the same software.

## Guided material from the sources this reference cites

- PortSwigger Web Security Academy — <https://portswigger.net/web-security>. Topic pages and labs for the classes in `methodology/vulnerabilities/`. The Academy is the right place to see a worked example. The finding you deliver to a client still describes their control, not a lab solution.
- OWASP Web Security Testing Guide — <https://wstg.owasp.org/>. Read the test you are about to perform, including its objectives and its remediation section.
- OWASP Cheat Sheet Series index — <https://cheatsheetseries.owasp.org/index.html>. Read the prevention sheet before you write the recommendation.
- MITRE ATT&CK — <https://attack.mitre.org/>. Use it to learn how defenders name activity. Pair a technique with the detections ATT&CK already lists.

## Practice platforms

- TryHackMe — <https://tryhackme.com/>.
- Hack The Box — <https://www.hackthebox.com/>.

Both publish their own rules about what you may attack. Their machines are in scope for an account in good standing. Nothing else you can reach from the same laptop is included.

## Writing and judgement

- SANS blog — <https://www.sans.org/blog/>. Useful for detection and response writing. A single post is not a standard. Cite it as commentary and cite NIST, ATT&CK, or OWASP for the requirement.
- NCSC vulnerability management collection — <https://www.ncsc.gov.uk/collection/vulnerability-management>. A public-sector view of prioritising and disclosing weaknesses that pairs well with the reporting notes.

## How to use a lab without picking up bad habits

- Keep the authorisation habit even when the target is a lab: know which host the platform gave you.
- Stop when you understand the failed control. Collecting a longer payload list does not make the lesson more true.
- Write the remediation in your notes before you look at the official solution, then compare. The remediation is the part a client pays for.
- Do not copy lab data, flags, or other people's write-ups into a client report.
